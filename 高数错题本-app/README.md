# 高数错题本 · 本地程序

一个跑在自己电脑上的错题本程序。**数据仍然是 `../高数错题本/` 里那些 Markdown 文件**，
程序只是给它们套了一层更好用的界面：总览统计、题库浏览、一键打卡。

---

## 启动

**方式一（最省事）**：双击桌面上的 **`启动高数错题本.command`**。
它会先探一下服务在不在：在就只开浏览器，不在就启动服务再开。

**方式二**：在访达里双击 `高数错题本-app/启动错题本.command`。

**方式三**：终端里执行

```bash
cd "高数错题本-app"
node server.mjs              # 启动并自动开浏览器
node server.mjs --no-open    # 只启动
node server.mjs --port 4200  # 换端口
```

打开后地址是 **http://127.0.0.1:4173**

> 窗口关掉服务就停了。想常驻，用方式三放在一个终端里别关。
> 首次双击 `.command` 若提示「无法打开」，执行一次：
> `chmod +x "高数错题本-app/启动错题本.command"`

**环境变量**（临时指向别的错题本，做实验用）

```bash
NOTEBOOK_DIR=/tmp/另一份错题本 NOTEBOOK_PORT=4199 node server.mjs --no-open
```

## 数据存在哪

| 位置 | 作用 |
| --- | --- |
| `../高数错题本/**/*.md` | **唯一数据源**。程序读写的就是这些文件本身 |
| `backups/YYYY-MM-DD/` | 每次写入前的自动备份（同一天同一篇只留首次备份） |
| `data/questions.json` | 导出的机器可读快照 |
| `data/stats.md` | 导出的 Markdown 统计报告（可直接在 Obsidian 里看） |
| `config.json` | 错题本路径、端口、监听地址 |

**没有任何隐藏数据库。** 删掉这个程序目录，错题本一个字节都不会少；
Obsidian 里照样能看、能改、能 git。

## 设计上的三条纪律

1. **定点写回，绝不整篇重写。**
   程序只会改动三处：frontmatter 的 `difficulty` / `heat` / `type`、
   笔记末尾的 `## 打卡记录` 区块、以及「本题档案」里对应的那两行。
   标题、题干、答案、解析、公式、空行——全部原样不动。
   已验证：打卡后再撤销，文件与原始状态**逐字节一致**（sha256 相同）。

2. **格式不对就只读不写。**
   缺少 `## 打卡记录`、frontmatter 缺字段等情况的笔记，界面会打黄色提醒，
   并且拒绝为它打卡，绝不猜测、绝不硬写。

3. **写入前先备份。**
   每条 `backups/日期/` 下的副本都可以直接覆盖回去。

## 打卡规则

每道题做完一次，在详情页点一个结果：

| 结果 | 含义 | 题目状态 |
| --- | --- | --- |
| ✅ 完美 | 独立做对、思路清楚 | **复习完成** |
| 🟡 普通 | 做出来了但不顺 | 待复习 |
| ❌ 失败 | 没做出来 / 做错 | 待复习 |

**只要打卡记录里出现过一次「完美」，这道题就算复习完成**，之后即使又失败也不会打回（
如果你想要「完美后再失败就打回待复习」，改 `lib/stats.mjs` 里 `summarize` 的判定即可）。

程序会把记录写回 Markdown，格式为：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13
- [x] 第 2 次 · 完美 · 2026-09-14

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

所以**在 Obsidian 里手动勾这些复选框，程序同样能读到**——两边随时可以混用。
点错了在详情页的打卡时间线上点「撤销」即可。

> ⚠️ 如果手动加记录，**「完美 / 普通 / 失败」这三个词要原样写**，统计是靠文字匹配的。

## 界面

- **总览**：统计卡（题数 / 完成率 / 待复习 / 累计打卡 / 连续天数）、
  章节分布环形图、数一热度与难度分布、近 30 天打卡曲线、
  「待复习·按优先级」表（热度权重最高，失败过的加权前移）、「失败过的题」表。
- **题库**：左侧按章节 / 状态 / 难度 / 热度筛选，右侧卡片列表，点开进详情。
- **详情抽屉**：一屏看完——类型、难度（点星即改）、热度（点火即改）、
  三个打卡按钮、打卡时间线（可撤销）、题干、以及四个折叠块
  （核心考点与主要难点 / 答案 / 解析 / 易错提醒）。
- **复习**：一题一屏的刷题模式，见下。
- `⌘K` 搜索，`Esc` 关抽屉，右上角 `◐` 切深浅色。
- 地址栏带 hash 可深链：`#dashboard` / `#library` / `#review`。

## 复习模式

进「复习」页先选四件事，再点「开始复习」：

| 选项 | 取值 |
| --- | --- |
| 复习范围 | 全部章节，或勾选若干章节 |
| 抽哪些题 | 只抽待复习 / 只抽失败过 / 全部题目 / 只抽已完成 |
| 出题顺序 | 按优先级 / 最热优先 / 纯随机 |
| 本局题数 | 5 / 10 / 20 / 全部 |

「按优先级」= `热度×2 + 难度 − 已打卡次数×0.5 + 失败过×1.5`，再叠一点随机抖动，
所以每次顺序不完全一样，但**最该做的题总在前面**。

**键盘流**（手不用离开键盘）：

| 键 | 作用 |
| --- | --- |
| `空格` | 显示答案与解析 |
| `1` | 记「完美」并进入下一题 |
| `2` | 记「普通」并进入下一题 |
| `3` | 记「失败」并进入下一题 |
| `S` | 跳过这题（不计入打卡） |
| `Esc` | 退出本局 |

每记一次结果，程序立刻把打卡写进对应的 Markdown 文件，**不需要结束时统一保存**。
一局结束出成绩单：完美 / 普通 / 失败 / 跳过 各几题、总用时、平均每题用时、逐题结果
（点某一行可以回看那道题）。

## HTTP 接口

程序跑着的时候，这些接口可以直接读（也可以被其它脚本调用）：

```
GET   /api/health                自检
GET   /api/questions             全部题目（含打卡记录与统计）
GET   /api/stats                 总览统计
POST  /api/checkin               { id, result, date? }
POST  /api/undo                  { id, attempt, result }
PATCH /api/question              { id, difficulty?, heat?, type? }
POST  /api/export                导出 data/questions.json 与 data/stats.md
```

## 自动化测试

`test/e2e.mjs` 会用无头 Edge 真的点一遍界面：渲染总览、切题库、筛选题型、
开详情抽屉、进复习模式、按空格看答案、按 `1/2/3` 记结果、出成绩单、
并校验打卡确实写回了文件。

```bash
# 1) 起一个指向「副本」的测试服务，绝不动真数据
cp -R 高数错题本 /tmp/notebook-test
NOTEBOOK_DIR=/tmp/notebook-test NOTEBOOK_PORT=4199 node server.mjs --no-open &

# 2) 起无头 Edge（开调试端口）
"/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge" \
  --headless=old --disable-gpu --no-sandbox --remote-allow-origins='*' \
  --remote-debugging-port=9333 --user-data-dir=/tmp/edge-e2e \
  --window-size=1500,1150 "http://127.0.0.1:4199/" &

# 3) 跑测试
node test/e2e.mjs          # 截图输出到 /tmp/e2e-*.png
```

## 加新题

目前仍需**手动新建 Markdown**（照抄 `高数错题本/_错题模板.md`），放进对应章节文件夹即可，
程序刷新后自动收录。

「粘贴题干 → 自动分章节成篇」的增题页在阶段三，见下方路线图。

## 路线图

- [x] **阶段一** 总览统计 + 题库浏览 + 打卡写回
- [x] **阶段二** 复习模式（抽题 / 键盘流 / 计时 / 成绩单）
- [ ] **阶段三** 增题页（粘贴题干 → 自动成篇）
- [ ] **阶段四** 错题互链（同考点关联）+ 遗忘曲线重做提醒

## 手机上用

把 `config.json` 的 `host` 改成 `"0.0.0.0"`，重启后用 `http://<电脑局域网IP>:4173` 访问。

> ⚠️ 这等于把**能改你错题本**的接口暴露在局域网里，只在可信网络下这么做。

# study · Error-notebookyu

考研学习台。**Obsidian 存数据，本地程序管复习。**

> 📒 **笔记、计划、复盘都不入库。** 这些是私人内容，只留在本地 Obsidian；
> 这个仓库只放程序。

- 🖥️ [`study-app/`](study-app) —— 本地程序，五个页面：今日 / 错题 / 计划 / 笔记 / 复盘
- 📒 本地目录（都不在仓库里）：
  `错题本/`（错题）· `考研/`（月计划 + 周计划）· `复盘/`（每日复盘）· `高等数学/` 等（学习笔记）

## 程序能做什么

- **今日**：考研倒计时、今天要做的任务（勾选直接写回 Obsidian 的周计划）、本周七天进度条、错题待复习数
- **错题**：四层总览、题库筛选、全屏做题模式、按遗忘曲线复习、考点标签、错因分析、图片转题目
- **计划**：月计划与周计划浏览，任务复选框直接改原文件
- **笔记**：`高等数学/` 等目录的笔记浏览，公式渲染
- **复盘**：按日期写到 `复盘/26.9/第二周/9.13复盘.md`，Obsidian 里立刻可见

## 每道错题长什么样

正文开头只有三行：**考的类型 · 难度 · 考研热度**。
答案、解析、核心考点与主要难点、易错提醒、错因分析**全部折叠**，点标题才展开。
最底下是打卡区，做完一次勾一个结果：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13 · 245s · 错因：计算失误
- [x] 第 2 次 · 完美 · 2026-09-14 · 192s

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

做到「完美」即按 **1 / 2 / 4 / 7 / 15 / 30 天** 的遗忘曲线排期；到点自动变「⏰ 该复习了」。

## 跑起来

```bash
cd 错题本-app
node server.mjs          # 自动打开 http://127.0.0.1:4173
```

零依赖、不联网（KaTeX 已离线内置）。详见 [`错题本-app/README.md`](错题本-app/README.md)。

## 设计原则

1. **Markdown 是唯一数据源。** 没有隐藏数据库，删掉程序数据也不会少一个字节。
2. **定点写回。** 程序只改 frontmatter 的难度/热度/考点，末尾打卡区，以及档案与错因那几行；
   正文与公式原样不动。已验证「打卡 → 撤销」后文件 sha256 逐字节还原。
3. **格式不对就只读不写**，并在界面上标黄提醒。
4. **写入前自动备份**到 `错题本-app/backups/`。
5. **图片只做暂存。** 上传的题目截图不会被直接引用进笔记 —— 程序生成提示词，
   由 AI 看懂后重写题干、用代码重画图形。

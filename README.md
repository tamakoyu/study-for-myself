# 错题本 · Error-notebookyu

考研错题本。**Markdown 存数据，本地程序管复习。**

- 📒 [`错题本/`](错题本) —— 错题本身，纯 Markdown，Obsidian 直接可读
- 🖥️ [`错题本-app/`](错题本-app) —— 本地程序：总览统计 / 题库浏览 / 刷题 / 增题

```
错题本/
```

## 每道错题长什么样

正文开头只有三行：**考的类型 · 难度 · 考研热度**。
答案、解析、核心考点与主要难点、易错提醒**全部折叠**，点标题才展开。
最底下是打卡区，做完一次勾一个结果：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13
- [x] 第 2 次 · 完美 · 2026-09-14

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

勾到「完美」即为复习完成；只有「普通 / 失败」的仍算待复习。

## 跑起来

```bash
cd 错题本-app
node server.mjs          # 自动打开 http://127.0.0.1:4173
```

零依赖、不联网（KaTeX 已离线内置）。详见 [`错题本-app/README.md`](错题本-app/README.md)。

## 设计原则

1. **Markdown 是唯一数据源。** 没有隐藏数据库，删掉程序数据也不会少一个字节。
2. **定点写回。** 程序只改 frontmatter 的难度/热度、末尾打卡区、以及档案那两行；
   正文与公式原样不动。已验证「打卡 → 撤销」后文件 sha256 逐字节还原。
3. **格式不对就只读不写**，并在界面上标黄提醒。
4. **写入前自动备份**到 `错题本-app/backups/`。

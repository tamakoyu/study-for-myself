# study · Error-notebookyu

考研学习台。**Obsidian 存数据，本地程序管复习。**

> 📒 **笔记、计划、复盘都不入库。** 这些是私人内容，只留在本地 Obsidian；
> 这个仓库只放程序。

- 🖥️ [`study-app/`](study-app) —— 本地程序，八个页面：今日 / 测试 / 单词 / 错题 / 好题 / 题型 / 计划 / 复盘
- 📱 **同一个服务的手机做题端 `/m`** —— 手机上打开 `http://<电脑局域网IP>:4173/m`，
  只有「今日 / 做题」两屏：**看题 → 在纸上写 → 拍照传上来 → AI 判 → 记进笔记**，
  和电脑端共用一份 Markdown（勾任务、打卡、判分都直接写盘，电脑上刷新就能看到）
- 📒 本地目录（都不在仓库里）：
  `错题本/`（错题）· `好题本/`（好题）· `题型本/`（每个题型一份通解）·
  `考研/`（月计划 + 周计划）· `复盘/`（每日复盘）·
  `单词故事/`（考研英语一题目）· `今日测试/`（按今天学的出的题）
- 📖 Obsidian 里**只显示学习笔记**（`高等数学/`、`高数上知识前探/`、`数据结构/`、`费曼自测清单/`），
  其余目录都加进了忽略列表
- 🔗 程序里也能**只读地看笔记原文**（图片、公式、`[[双链]]` 都能用），
  每道题都能一键跳到它的源文件，再顺着双链一路看下去

## 程序能做什么

- **今日**：考研倒计时、今天要做的任务（勾选直接写回 Obsidian 的周计划）、本周七天进度条、错题待复习数，
  以及**墨墨背单词的今日进度与总量**（今日完成 / 剩余 / 学习时长、计划总量、今日到期、易忘词）
- **内置 AI**：程序里直接调模型（OpenAI 兼容：DeepSeek / Kimi / 智谱 / 通义 / 硅基流动 / OpenAI / 本地 Ollama），
  配好之后**点一下就自动生成并写盘**，不用再复制提示词给 AI；没配也能用「复制提示词」那条老路
- **今日测试**：按今天的数学 / 408 计划 **+ 今天刚记的笔记**出题，**总分 100 分、每题都算好分值**；
  全屏做，**自带计时器与参考用时**（**交卷判分后自动停**，判分等模型的时间不算用时），答案与解析默认藏着，
  **做完把整份手写答案拍照传上来 → 内置 AI 按考研阅卷标准逐题打分**（大题按步给分），
  成绩单直接显示在题目下面，**一键把这次做错的题全收进错题本**（错因、丢分点、该怎么改一起写进去）；
  某一题也能单独收进错题本 / 好题本
- **单词**：接墨墨开放 API 读背词数据；勾几个词 + 选题型（完形 / 传统阅读六种 / 新题型）
  → 按考研英语一生成整套题存进 `单词故事/`，**全屏做题**，原文里目标词标蓝，选项可点、
  **本地判卷按每题分值给分**（单篇 10 分：阅读 5 题 × 2、完形 20 空 × 0.5），同样**带计时器与参考用时**（**对完答案自动停**）
  （一篇阅读 18 分钟）；**左原文 / 右侧栏**的版式 —— 题目、答案解析、生词回收、中文大意都在侧栏里，
  侧栏能折叠（收起时原文回中间、打开时原文让位到左边），成绩也记进这一篇
- **错题**：四层总览、题库筛选、全屏做题模式、按遗忘曲线复习、考点标签、错因分析、图片转题目。
  **全屏做题也带计时器（可暂停 / 重置、刷新不丢）与「参考用时」**（优先用这道题自己的平均用时）；
  纸上写完了可以直接**拍照让内置 AI 判这一题**：给 0–100 的得分 + 「完美 / 普通 / 失败」建议
  + 错因 + 错因分析，**记录什么自己在面板上改完再写**（结果进打卡、错因进首次错因、分析进 `## 错因分析`）
- **好题**：和错题本同一套功能，只是不收错因。**两本书彻底分开** ——
  各自的编号、统计、复习队列、增题提示词；题库可以选「全部（共通）」一起看，卡片上标出来源
- **题型**：把错题/好题归纳成「通解」，一个题型一份；难度、考研热度、掌握度（由关联题算出）。
  点一下进「大屏」整页看通解；**归类不用手动触发** —— 在增题页生成提示词时就会带上全部已有通解，
  能并进去的只改关联，新题型才新建
- **原文**：题目详情里「📄 本题原文」，点了直接在程序里渲染 Obsidian 那篇笔记
- **计划**：月计划与周计划浏览，任务复选框直接改原文件
- **复盘**：按日期写到 `复盘/26.9/第二周/9.13复盘.md`，Obsidian 里立刻可见
- **📱 手机做题（`/m`）**：手机浏览器打开就能用，只有「今日 / 做题」两屏 ——
  今天要做什么、待复习几道、**拍手写答案 → AI 按考研标准判 → 错因/错因分析改完再记进笔记**；
  相机和相册两个入口分开给（拍照原图先在手机本地缩到长边 2000 再传），
  计时器和电脑端同一套（锁屏刷新不丢），**记完直接写进同一份 Markdown**。
  手机上不配置 AI，接口和 key 在电脑上填好即可

## 每道错题长什么样

正文开头只有三行：**考的类型 · 难度 · 考研热度**。
答案、解析、核心考点与主要难点、易错提醒、错因分析**全部折叠**，点标题才展开。

**答案栏按题的大小分两种写法**：小题给最终结果 + 一句校验；
**大题（解答 / 证明）给的是考场上写在答题卡上的完整标准过程** ——
以「解：」开头、一步一依据、行间公式单独成段、分类讨论写全、结尾出结论；
「解析」块只写思路与易错点，不重复过程。

最底下是打卡区，做完一次勾一个结果（**次数不封顶**）：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13 · 245s · 错因：计算失误
- [x] 第 2 次 · 完美 · 2026-09-14 · 192s

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

**做了就算「已复习」，任何结果都会排下一次**：做错 → 明天；做对一次 → 4 天；
**之后每做对一次翻一倍**（8 → 16 → 32 → 64 → 128 … 没有上限，连对 8 次的题一年多以后才回来）；
普通 → 降一级。到日子自动变「⏳ 待复习」回到队列。
状态只有 **已复习 / 待复习 / 未做** 三种，「待复习」= 刚加的 + 复习到期的。

## 跑起来

```bash
cd study-app
node server.mjs          # 自动打开 http://127.0.0.1:4173
                         # 启动时会同时打印手机端地址 http://<局域网IP>:4173/m
```

零依赖、不装包（KaTeX 已离线内置）。**除了「单词」页要联墨墨、内置 AI 要联模型服务，其余全部本地跑**；
墨墨读不到时会退成一句提示，首页照常打开。详见 [`study-app/README.md`](study-app/README.md)。

> 📱 手机在同一 Wi-Fi 下打开打印出来的那个 `/m` 就能做题（拍手写答案 → AI 判 → 记进笔记）。
> **开不开在设置页里一个开关说了算**（⚙ 设置 → 📱 手机访问），拨一下立刻生效、不用重启；
> 关掉之后局域网是真的连不上（不是回一句 403），电脑这边不受影响。
> 开着 = 同一个网络里的人都能打开、也能改你的笔记，公共 Wi-Fi 下记得关。

## 设计原则

1. **Markdown 是唯一数据源。** 没有隐藏数据库，删掉程序数据也不会少一个字节。
2. **定点写回。** 程序只改 frontmatter 的难度/热度/考点，末尾打卡区，以及档案与错因那几行；
   正文与公式原样不动。已验证「打卡 → 撤销」后文件 sha256 逐字节还原。
3. **格式不对就只读不写**，并在界面上标黄提醒。
4. **写入前自动备份**到 `study-app/backups/`。
5. **图片只做暂存。** 上传的题目截图不会被直接引用进笔记 —— 程序生成提示词，
   由 AI 看懂后重写题干、用代码重画图形。

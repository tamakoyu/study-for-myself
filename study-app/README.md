# study · 考研学习台

**Obsidian 存数据 + 本地程序管复习**。八个页面：
今日 / 测试 / 单词 / 错题 / 好题 / 题型 / 计划 / 复盘。
除了「单词」页要联墨墨的开放 API，其余页面都直接读写你 Obsidian 里的 Markdown。

> 笔记主要在 Obsidian 里写。程序里也能**只读地看**一篇笔记的原文（题目的源文件，
> 图片和 `[[双链]]` 都能点），不用切窗口对照。Obsidian 里现在**只留笔记**，其余目录全部隐藏。

> 程序进 git，**笔记 / 计划 / 复盘都不进 git**（私人内容，只留本地 Obsidian）。

| 目录 | 内容 | 在程序里 |
| --- | --- | --- |
| `错题本/` | 错题，`<大类>/<科目>/<章节>/题目.md` | 「错题」页 |
| `好题本/` | 好题，格式与错题本**完全一样，只是没有错因分析** | 「好题」页 |
| `题型本/` | 每个题型一份「通解」 | 「题型」页 |
| `考研/` | 月计划 + 周计划（勾选状态就写在这些文件里） | 「计划」页 + 首页今日任务 |
| `复盘/` | 每日复盘 `26.9/第二周/9.13复盘.md` | 「复盘」页 |
| `单词故事/` | 考研英语一题目 `2026-09-14-01-传统阅读·细节题.md` | 「单词」页（全屏做） |
| `今日测试/` | 按今天学的出的题 `2026-09-14-今日测试.md` | 「测试」页（全屏做） |
| `高等数学/` 等 | 学习笔记 | 主要留在 Obsidian 里看；程序里顺着 `[[双链]]` 也能只读打开（`config.json` 的 `noteDirs`） |

```
错题本/
├── 数学/{高数, 线代, 概率论}/<章节>/*.md
└── 408/{数据结构, 计算机组成原理, 操作系统, 计算机网络}/<章节>/*.md
```

## 启动

**方式一（最省事）**：双击桌面上的 **`启动错题本.command`**。
它会先探服务在不在：在就只开浏览器，不在就启动服务再开。

**方式二**：访达里双击 `study-app/启动错题本.command`。

**方式三**：终端

```bash
cd study-app
node server.mjs              # 启动并自动开浏览器
node server.mjs --no-open    # 只启动
node server.mjs --port 4200  # 换端口
```

打开后地址是 **http://127.0.0.1:4173**

> 窗口关掉服务就停了。首次双击 `.command` 若提示「无法打开」，执行一次：
> `chmod +x "study-app/启动错题本.command"`

**环境变量**（临时指向另一份仓库，做实验 / 跑测试用）

```bash
# 整套指到另一份仓库：错题本 / 好题本 / 题型本 / 计划 / 复盘 / 笔记目录全部跟着走
VAULT_DIR=/tmp/另一份仓库 NOTEBOOK_PORT=4199 \
  BACKUP_DIR=/tmp/试验/backups UPLOAD_DIR=/tmp/试验/uploads EXPORT_DIR=/tmp/试验/data \
  node server.mjs --no-open
```

| 变量 | 作用 |
| --- | --- |
| `VAULT_DIR` | 整个仓库换位置（仓库内所有目录跟着走） |
| `NOTEBOOK_DIR` / `GOOD_DIR` / `PATTERN_DIR` | 单独换某一本 |
| `STORY_DIR` / `TEST_DIR` | 单独换单词故事 / 今日测试目录 |
| `BACKUP_DIR` / `UPLOAD_DIR` / `EXPORT_DIR` | 程序自己的目录换位置（测试时别污染真的备份） |
| `NOTEBOOK_PORT` | 换端口 |
| `NOTEBOOK_CONFIG` | 把 `config.json` 指到别处（跑测试用，免得拨一下「手机访问」开关就改了你真在用的配置） |
| `MAIMEMO_TOKEN` | 墨墨 token（优先于 `.maimemo-token` 文件） |
| `MAIMEMO_OFF` | 设成 `1` 就完全不联墨墨，一个请求都不发（离线 / 跑测试用） |
| `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY` | 内置 AI 的配置，**优先于** `.ai-config.json` |
| `AI_CONFIG_FILE` | 把 AI 配置指到别处（跑测试用，别污染真配置） |

## 八个页面

> 📱 手机上另有一套**只做「看题 + 拍照上传 + 判分 + 记笔记」**的做题端：`/m`，见
> [手机上用](#手机上用做题端-m)。下面这八个页面是电脑上的。

### ⓪ 今日

- **考研倒计时**：距 2027-12-18 还有多少天（`config.json` 的 `examDate` 可改）
- **每日一句**（倒计时右边）：内置 **460 句**，一天一句，**跨天自动换**，不用管它。
  句子来自毛选 / 认知觉醒 / 被讨厌的勇气 / 蛊真人，加上中外经典、诗词、网文动漫影视里的
  激励句和人生至理。同一天永远同一句（刷新、重启都一样），走满 460 天再从头轮。
  想加自己的句子：写进 `study-app/quotes.txt`（一行一句 `句子 | 出处`），改完刷新即可。
  出处见 `lib/quotes.mjs`
- **今天的任务**：从本周周计划里挑出标了今天日期的条目，加上没标日期的本周待办，
  **勾一下直接写回 Obsidian**（补 ` ✅ 日期`，和你原来的习惯一致）。
  任务标题里的 Markdown（`**加粗**`、`` `代码` ``、`[[双链]]`）会**按格式渲染**，不会把星号原样显示
- **🔁 每日任务按天算**：以 `🔁` 开头的任务（「每天都要做」）程序每天都列出来，但**勾的是哪一天**——
  模板行永远是 `- [ ]`，打过卡的日期记在它下面的子行里，所以**第二天不会还带着昨天的勾**：

  ```markdown
  - [ ] 🔁 每日单词 130 个（墨墨背单词）
    - [x] 2026-09-14
    - [x] 2026-09-15
  ```

  任务右边显示「本周 x/7」的打卡进度。**完成率也按天算**：一条每日任务一周占 7 个位子
  （4 条 = 28 个），打过几天卡就算几个 —— 「本周 / 本月完成率」「本周七天进度条」「计划页每组的
  x/y」说的都是同一件事。周计划里**以前那种整行带勾的旧写法**
  （`- [x] 🔁 … ✅ 日期`）在下次勾选时会自动迁成子行，历史不丢；想一次性把旧文件全迁干净：
  `node scripts/daily-checkins.mjs` 先预演，加 `--apply` 真正写入（自动备份）
- **本周进度**：一周七天的完成条 + 本周 / 本月 / 错题掌握度三条进度。
  **那排日期每一格都能点** —— 点周三就换成「9/16（周三）的任务」，看看那天要做什么、
  哪几项勾了、那天的每日任务打没打卡；标题旁边出现「← 回到今天」。
  地址栏会变成 `#today/2026-09-16`，刷新、收藏、发给手机都还在那一天。
  **翻回过去的那天勾一下，就补在那一天上**（🔁 记当天打卡、普通任务记当天的完成日期）；
  还没到的日子只给预览，复选框是禁用的
- **四张统计卡**：今日完成 / 本周完成率 / 错题待复习 / 连续打卡
- **今日单词**（在「本周状态与建议」上面）：墨墨的今日进度用**环形图**表示（已完成 / 还剩），
  右边两条比例条是「今日到期」「易忘词」占计划总量的比重。
  **读不到墨墨的数据也不会打不开首页**，只是这张卡换成一句原因
- **本周状态与建议**：见下
- 一键进「写今日复盘」或「去刷错题」

> 首页板块顺序：倒计时 → 今天任务 / 本周进度 → 四张统计卡 → **今日单词** → **本周状态与建议** → 本周剩余。

### ⚙️ 设置（顶栏右上角的齿轮）

专门一页放所有配置，不再散落在各个页面里：**🤖 内置 AI**、**📖 墨墨 token**、**🩺 自检**、
**📱 手机访问**、**🔁 服务**。

- **自检**一键依次试：本地服务 → 墨墨接口 → 模型接口，每条都如实报结果和耗时
- **手机访问**一个开关，控制「别的设备能不能连上这个服务」——
  拨一下**立刻生效、不用重启**，详见 [手机上用](#手机上用做题端-m)
- 两个 key 都只写本机（`.ai-config.json` / `.maimemo-token`，600 权限 + gitignore），
  **接口永远不回显**，页面上永远是空的密码框

#### 🔁 一键重启服务

改完 `server.mjs` 或 `lib/` 里的东西**要重启才生效** —— 以前得回终端 Ctrl+C 再敲一遍
`node server.mjs`。现在设置页底下就有一个按钮：

```
🟢 服务在跑：PID 64281　·　端口 4173　·　已运行 12 分钟        [🔄 重启后端] [⟳ 刷新状态]
```

- **两段式确认**（和删除一个规矩）：点一下变「确认重启？再点一次就重启」，5 秒不点自动解除
- **点完自动刷新页面**：老进程退出的那一刻页面就断了，所以程序会一直轮询 `/api/health`，
  等 **pid 变了**（= 新进程真的起来了）自动刷新，不用自己盯着按 F5
- **重启是换了新进程**，不是「假装重启一下」：端口、`VAULT_DIR` 等环境变量原样继承，
  仓储配置（`notebookDir` 等）跟着一起回来
- 新进程带 `--no-open`（不会又弹一个浏览器窗口），输出追加到 `study-app/.server.log`
- 按钮名字就是 **🔄 重启后端**，没有别的玄机 —— 点了就重启，没配什么开关

> 为什么不能自己重启自己：处理重启请求的就是**老进程**，它得先退出把端口让出来，
> 新进程才能 bind。所以它叫一个**看门人**（`scripts/relaunch.mjs`，脱离父进程）：
> 看门人轮询端口 → 空了再把 `server.mjs` 拉起来。

### ⓪.1 内置 AI（点一下直接生成，不用再复制粘贴）

程序里内置了**调用模型**的能力，所以「生成提示词 → 复制给人 → 人写完再回来」这条路可以省掉了：
配好之后，**点「🤖 直接生成」，程序自己调模型、自己解析、自己写盘**，写完页面直接刷新出来。

只认一种协议：`POST {地址}/chat/completions`（OpenAI 兼容），所以这些都能直接用：

| 预设 | 地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-flash`（V4.1-Flash） |
| Kimi 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:14b`（不需要 key） |

**怎么配**：顶栏右上角 **⚙ 设置** → 点一个预设（自动填地址和模型）→
粘上 key → 「保存」→ 「测试连接」看到「通」就行。
仓库里已经预填好 DeepSeek 的地址和 `deepseek-flash`，只剩 key 要自己填。

> key 只写进本机 `study-app/.ai-config.json`（600 权限，已 gitignore），
> **接口永远不回显它**，页面上那个框永远是空的密码框。
> 也可以用环境变量 `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY`（**优先级高于配置文件**，
> 界面上会明确提示「有环境变量在生效，在这里改不生效」）。

#### 哪四个地方能「点一下直接生成」

| 页面 | 按钮 | 干什么 |
| --- | --- | --- |
| 单词 | **生成 N 道题** | 按勾选的题型和词出整套题（选 3 道 = 3 次调用 = 3 个文件） |
| 测试 | **生成今日测试** | 按今天学的数学 / 408 / 笔记出题 |
| 今日 | **生成本周总结** | 读本周计划、复盘、错题，写进 `## 🤖 本周状态与建议` 那一节 |
| 增题 | **生成并写入错题本 / 好题本** | **一个按钮**同时处理粘的题干和传的图：识别分类 + 解题 + 写好完整笔记 |

> **只有内置生成这一条路**了：按钮名就直接是「生成 N 道题 / 生成今日测试 / 生成本周总结 / 生成答案与解析」。
> 没配 AI 时不显示按钮，而是给一句「去 ⚙ 设置填一下」的提示。

三种落盘方式，各按各的来：

| 任务 | 模型返回什么 | 怎么落盘 |
| --- | --- | --- |
| 考研题 / 今日测试 | `{"files":[{"rel","content"}]}` | 整篇写盘（校验 rel 必须是我们指定的路径） |
| 本周总结 | **一段纯 Markdown 正文** | 程序把它**插进周计划的那一节**，其余正文一个字节不动（再生成是整段替换，不会越写越长） |
| 增题 | `{"items":[…]}` | 模型**只负责解题**（答案 / 解析 / 考点 / 难度），笔记文件由程序按固定模板生成 —— 格式一定对 |

#### 生成时发生了什么

| 步骤 | 说明 |
| --- | --- |
| 建 job | 一个 job = **一次模型调用 = 一个文件**。选 3 篇阅读就是 3 次调用、3 个文件 |
| 流式调用 | `stream: true`，按 SSE 解析，边生成边把**字数**推到页面上 |
| 只吐 JSON | 提示词末尾追加一段「程序调用」指令，要求模型只返回 `{"files":[{"rel","content"}]}` |
| 解析 | 容错解析：裸 JSON / 被代码围栏包住 / 前后有解释文字 / LaTeX 反斜杠没转义 / 尾逗号 / 字段名写成 `path`，都能抠出来 |
| 落盘 | 校验 `rel` 必须是我们指定的路径，然后一篇一篇写盘（写一篇就成功一篇） |
| 刷新 | 全部跑完自动刷新列表，并把新生成的那篇打开 |

**为什么一个文件一次调用**：一次要 6 篇阅读（每篇 400+ 词、5 道题、解析、逐句分析、长难句拆解）能到两万多 token，
很容易被 `max_tokens` 截断，而截断后整个 JSON 都废了。拆开之后进度看得见，失败也只损失一篇。

**用词范围**：提示词里写死了两条 ——

1. 除目标词外，**用词严格限定在考研英语（一）大纲词汇范围内**（约 5500 词，含常见派生），
   不出现生僻词和俚语；
2. **万一必须出现大纲外的词**（专有名词、行业术语、新事物名、缩写），
   **在文中就地注释**：第一次出现时写成 `superconductor（超导体）` 这种形式，
   同一个词只注第一次，之后直接用。**目标词和纲内词都**不加注释（那是要背的 / 本来就该会）。

#### 增题页只有一个按钮

粘题干和传图片**走同一个按钮**，按手头有什么自动决定跑哪些任务：

```
生成并写入错题本（3 道题干 + 2 张图）     ← 按钮上直接标出来
```

- 只粘了题干 → 解题写笔记
- 只传了图 → 看图写笔记
- 两样都有 → 一起处理，一个进度列表跑完

**图片可以直接 ⌘V 粘贴**（macOS 上 Cmd+Ctrl+Shift+4 截完就能贴，不用先存文件），
也可以拖进虚线框或点「选择文件」。

#### 看图写题（多模态）

模型**直接看图**把题写成笔记：

1. **不要原图**：你看懂图里的内容之后，用**文字 + LaTeX** 把题干完整重写出来
2. **图形用 SVG 重画**：函数图像、几何图、二叉树、流程图、地址划分图… 模型输出一整个 `<svg>…</svg>`
   （文本，能落盘、Obsidian 直接显示），存到 `<错题本|好题本>/picture/` 再 `![[名字.svg]]` 引用
   —— 模型没法生成 png/jpg 这类二进制图，所以统一走 SVG
3. **一张图多道题就拆成多篇**
4. 模型给的文件**逐条校验**：只能写进错题本 / 好题本，越界路径直接拒收并在界面上报出来；
   写进去的笔记还要过一遍程序自己的解析器，**格式写得不对会提示**，不会默默收下

> 多模态走的是 OpenAI 的 `content: [{type:'image_url'}, …]` 格式，图片以 base64 data URL 传。
> 实测 `deepseek-flash` 能正确读图。

#### ⚠️ 思考模式（踩过的坑）

DeepSeek 的 `deepseek-flash` 这类模型会**先「思考」再回答**，而思考也算输出 token。
额度被思考吃光时，`content` 就是空的 —— 表现出来就是「测试连接一直不通过」。

所以：

- 连接测试固定用 `reasoning_effort: 'none'` + 给足 `max_tokens`（512），一句话的请求没必要思考
- 生成时按任务给默认档位：**英语出题关思考**（快）、**数学 / 408 出题和解题开「中」**（准）、周总结「低」
- 设置页有 **思考模式** 选项（自动 / 关 / 低 / 中 / 高），可以自己调
- 空内容时不再只说「模型返回了空内容」，而是告诉你**是被思考吃光了还是被 max_tokens 截断了**

**降级链**：JSON 模式 → 流式 → 非流式 → 去掉 `reasoning_effort`，逐级退让；
模型不支持 `response_format`、流式或思考参数都能跑。
**失败如实报**：某一篇失败了会标红写清原因，不会假装成功。
**关掉页面就中断**：客户端断开 → 服务端 abort 掉模型请求。

> 没配 AI 也完全能用 —— 只是退回「📋 生成提示词 → 复制发给我」那条路，两个按钮并排存在。

### ⓪.3 今日测试

**只考今天学的东西，而且题量按今天学了多少动态定。**

程序把「今天学了什么」整理成提示词，模型出题：

| 出题依据 | 从哪来 |
| --- | --- |
| 今天计划里的数学 / 408 | 本周周计划里标了今天日期的任务 ＋ 每天都要做的 |
| **今天刚记的笔记** | `noteDirs` 里 **mtime 是今天**的 `.md`（正文一起喂给 AI） |
| **今天的复盘** | 复盘里写的「今天学了什么、哪里没懂、哪里容易错」——最该拿来出题 |
| 薄弱点 | 错题本的考点标签统计 + 反复做错的题 |
| 今天没记笔记时 | 退而取**最近 3 天**的笔记，并在提示词里标明「不是今天的」 |

#### 题量按学习量动态定

程序先算一个「今天学了多少」（计划任务数 + 今日笔记数与字数 + 有没有写复盘），得出 **少 / 一般 / 多**，
连同对应的题量区间一起写进提示词：

| 判断 | 题量 | 时长 |
| --- | --- | --- |
| **多** | 6–8 道 | 30–40 分钟 |
| **一般** | 4–6 道 | 20–30 分钟 |
| **少** | 2–3 道 | 10–15 分钟 |

界面上也会显示这个判断：`今天学得 一般 → 约 20–30 分钟`。
**明确要求「不要为了凑数硬出题」**，也要求「宁可少出两道，也要把重要知识点覆盖全」。

出题策略是**先盘点、再出题**：模型先列出今天真正学到的重要知识点，然后**每个知识点至少出一道题**
（而不是逮着一个点连出五道）。考完要能回答「今天学的东西我是不是都过了一遍」。

#### 题型跟着内容走

| 什么时候用 | 题型 |
| --- | --- |
| 今天讲了新概念 / 新术语 | **概念填空**（挖定义里的关键词） |
| 今天出现或复习了公式 / 定理 | **公式默写**（并注明适用条件） |
| 适合考辨析、边界条件、易混概念 | **选择题**（4 选项，干扰项要有道理） |
| 有明确结果的小题 | **填空 / 计算题** |
| 今天的主线知识点、需要完整过程 | **大题**（解答 / 证明） |

**基础阶段**（刚开始学、内容是入门概念）→ 多出概念填空和公式默写，不硬上大题
（比如 408 刚开始还在装环境、讲存储模型，就出概念填空而不是代码题）；
**进入计算 / 证明主线** → 多出计算题和大题。

#### 答案与解析

- **大题的标准答案 = 考场上写在答题卡上的完整过程**：以「解：」开头、一步一依据、结尾出结论，
  **不要「本题考察了…」那种中文讲解**
- **解析**逐步说清每一步为什么这么做、容易错在哪、对应今天哪条内容
- 选择题要写清**每个干扰项为什么错**

#### 页面

点「📋 生成今日测试」→ 我在 `今日测试/<日期>-今日测试.md` 写好 → 页面出现一份**全屏试卷**：

- **答案和解析默认全部藏着**，每题一个「显示答案」，顶部还有「全部显示 / 全部收起」
- 显示答案后，每题下面出现 **➕ 加入错题本 / ➕ 加入好题本**
- 每题标着**分值**（全卷正好 100 分）和**这道题的参考用时**

#### 分值 · 参考用时 · 计时器

**出题时就把分值算好**：每题标题末尾写 `｜ 12 分`，全卷加起来**必须正好 100 分**
（概念填空 / 公式默写 4–8 分、选择题 4–6 分、填空 6–10 分、大题 10–20 分）。
程序直接读这一行，判分、成绩单、折算都用它 —— **不缺省成「每道题一样多分」**。
老试卷（没标分值）会按满分平均分，并在页面上如实标一句。

**参考用时**：整卷的时长由出题时估的 `minutes` 给，再**按分值比例摊到每题**
（40 分钟的卷子里，60 分的大题就是 24 分钟）。页面上：
标题栏 `⏱ 05:12 / 参考 30:00`，每题旁边 `40 分`、`参考 12 分钟`。

**计时器**：一进全屏卷子就开始走，可以**暂停**（数字变灰）、**重置**。
按卷子各记各的，**存在浏览器本地** —— 刷新页面、切出去瞄一眼错题本，回来时间还在，
不会因为手滑点一下就白做。超过参考用时数字变红。

> **交卷就自动停**：点完「🤖 按考研标准打分」，计时**冻在交卷那一刻**，之后不再往上走。
> 判分要等模型想半天，那几分钟不是我的做题用时；不停的话，回头翻一眼这份卷子数字还在涨，
> 写进成绩记录的「用时」也就成了假的。想再做一遍点「重置」。

#### 拍照判分（**只有数学 / 408 需要**，英语不用）

纸上做完（大题写完整过程）→ 翻开卷子拍照 → 一次把整份（可以好几张）传上来 → 点「🤖 按考研标准打分」。

> **英语那一篇没有这一套**：全篇四选一，程序本地判就完了（见「单词」那一节），
> 让模型去认手写字母既慢又可能看错。

| 环节 | 怎么做的 |
| --- | --- |
| 传图 | 拖进来 / **⌘V 直接粘贴**（截图不用先存文件）/ 点「选择图片」，多张一次全传 |
| 判分依据 | 程序把**每题的题干、标准答案、解析、分值**连同图片一起交给内置 AI |
| 判分口径 | **考研阅卷标准**：大题**按步给分**（方法对、结果错只扣结果那一步；方法错、结论碰巧对不给分；漏讨论、跳步、记号自创都扣）；选择题填空对满错零；没做的、看不清的、题号对不上的如实标出来给 0 分，**不许猜** |
| 每题给我什么 | 你实际写了什么（`got`）、这一题多少分、判定（正确 / 部分正确 / 错误 / 未作答 / 看不清 / 题号对不上）、**丢分点**、**该怎么改**、**错因**（从错题本那 8 个固定词里选一个） |
| 总分 | **程序自己把每题加起来**，不采信模型报的总分；单题得分会被夹在 `[0, 满分]` 内；漏判的题按 0 分补上，一道都不会少 |
| 落盘 | 写进这份卷子的 `## 成绩记录` 一节（**只动这一节**，题干与标准答案一个字节不改），最新一次在最上面 |
| 顺手 | 判完把暂存的图片清掉；成绩记录在**重新生成这份卷子时会自动接回去**，不会被一次重出题抹掉 |

成绩单直接显示在题目下面：总分、用时 vs 参考用时、逐题的得分 / 判定 / 错因 / 丢分点、
总评、薄弱点、下一步。**历次成绩**收在下面的折叠里（第几次、哪天、多少分、用时）。

> **成绩单里的公式是真公式**：判分给的丢分点、总评、薄弱点里全是 LaTeX
> （`$\lim_{x\to 0}\frac{\sin x}{x}$` 这种），显示时按行内 Markdown + KaTeX 渲染 ——
> 不是一屏反斜杠命令和美元符号。落进「成绩记录」的也还是原样的 LaTeX，笔记里读着一样。
>
> 顺带一条程序上的坑：总评 / 薄弱点 / 下一步是**和 items 平级**的字段，
> 解析时只把 `items` 数组往外传，这三项当场就没了（成绩单上永远空着）——
> 所以判分这条路必须交给它**整份信封**（`parseItemsEnvelopeEx` 的 `envelope`）。

> 为什么是拍照而不是在页面上填答案：数学 / 408 的大题要在纸上写完整的过程，
> 考场上也是这么写的 —— 判分得看得懂手写。

#### 一键把错题加入错题本

判完分，成绩单右上角有一个 **「➕ 一键把 N 道错题加入错题本」**（N 只数**没拿满分的**题）：

- 一次把这次所有做错的题写进错题本，**题干 + 标准答案 + 完整解析**都带上（本来就在卷子里）
- **判分给的错因**直接填进 `**首次错因**`（不用事后一条条补）
- **丢分点 + 该怎么改**写进「易错提醒」 —— 这比一句笼统的「易错」有用得多
- 归类（大类 / 科目 / 章节）还是先按题干关键词识别好再写，考点用卷子里那道题的考点当标签
- 写完后按钮位置换成一句回执（已加入第几题），不会重复点

单个题目的「➕ 加入错题本」老路还在（显示答案之后），那条路可以逐题改错因 / 难度 / 热度 / 归类。

#### 删除

生成的试卷、英语题目、题库里的题**都能删**，三种都是**两段式确认**：
点一下变成「确认删除？」，再点一次才真删（5 秒没点自动解除）。鼠标移上去才会显出那个 🗑，
平时不干扰阅读。

删除是**先备份、再删**：文件会先复制到 `backups/<日期>/deleted-<原路径>`，
删错了能直接从那儿捞回来。删完列表立刻刷新，题库那边缓存也一并失效。

#### 加入题库：错题本该有的字段一个不少

点「加入」不是闷头写盘，而是**先弹一个填写面板**：

| 字段 | 怎么来的 |
| --- | --- |
| **错因** | 8 个固定词表（概念不清 / 方法不会 / 计算失误…）点选 —— 这是「你为什么会错」，只有你知道 |
| **考点** | 默认填测试里那道题的考点，可以改成多个（用「、」隔开），**没有的会自动新建** |
| **难度 / 考研热度** | 各 5 档点选 |
| **归类** | 程序按题干关键词**先识别好大类 / 科目 / 章节**再预填，不对就直接改 |

确认后才写盘，并且**题干 + 标准答案 + 完整解析一起写进笔记**，不用再等 AI 二次补。
文件名用题目的**考点**来起（`极限-01-左右极限与分段点.md`），不是从题干前几个字截的碎片。

> 好题本不收错因分析 —— 好题不是因为做错才收的。

### ⓪.5 单词（墨墨背单词 → 考研英语一题型）

**从墨墨挑词 → 选题型 → 生成提示词 → 复制给 AI → 得到按考研英语一出的一套题。**

页面从上到下三块：**今日单词（图表）→ 选词 · 选题型 → 篇目列表**（都占满整行，不左右并排）。
点开一篇就是**全屏阅读**：左原文 / 右侧栏（题目与解析类内容）。

#### 词从哪来（可多选）

| 来源 | 取自 | 说明 |
| --- | --- | --- |
| 今天没背完 | `get_today_items` | 今日词表里还没背、或者背了没记住的 |
| 今日新学 | `get_today_items` | 今天第一次背的新词（`is_new`） |
| 背了多次还不熟 | `query_study_records` | 复习过好几遍、最近一次还是模糊 / 忘记的；**阈值可选 2 / 3 / 5 次** |
| 易忘词 | `query_study_records` | 墨墨自己打了 `STICKING` 标的 |
| 今日新加 | `query_study_records` | 今天才加进墨墨计划的（`add_date` 是今天） |

> ⚠️ 后三类来自 `query_study_records`，而这个接口**一页最多 1000 条**，而且**不按日期排序、翻页翻不动**。
> 所以它们是在**前 1000 条记录里筛的**，计划超过 1000 词时会漏一点。界面上会如实标出来。

#### 选多少词

- **推荐**：按你选的题型自动算（传统阅读 15 词 / 篇，完形和新题型 12 词 / 篇），多篇相加
- **自定义**：直接填个数
- **不够自动补**：勾选的来源凑不够数量时，会自动从**整个词池**里补足，补进来的词在筹码上标「池外」
- 单个词可以点掉 / 点回来（点掉的不参与，点回来的会额外加上）

#### 题型（全部按考研英语一）

| 题型 | 考研英语一里长什么样 |
| --- | --- |
| 完形填空 | 240–280 词短文，20 个空，每空 A–D；首句不挖空；词义辨析 / 固定搭配 / 逻辑连接 / 语法按比例分布 |
| 传统阅读 · 主旨题 | **一整篇标准阅读**（400–450 词 / 5 题 / A–D），本篇重点练主旨题 |
| 传统阅读 · 细节题 | 同上，重点练细节题 |
| 传统阅读 · 推理判断题 | 同上，重点练推理题 |
| 传统阅读 · 猜测题 | 同上，重点练词义句意题（含熟词僻义） |
| 传统阅读 · 例证题 | 同上，重点练例证题 |
| 传统阅读 · 态度题 | 同上，重点练态度题 |

**「一题」＝ 一整篇考研阅读**：500 词上下、5 道小题、每题 A–D 四选项 —— 这就是英语一传统阅读的真题格式。
5 道小题的**题型按真题自然分布**（主旨/标题 1 · 细节 1–2 · 推理 1 · 词义句意 1 · 态度或例证 0–1），
**所选题型保证至少出现 1 道**，并在答案解析的「题型」一列标出来。所以选哪个题型是「这篇重点练它」，
出的永远是一篇完整的真题格式阅读，不会变成「5 道题全是同一个题型」那种四不像。
| 英1新题型 | 七选五 / 排序 / 小标题匹配三选一，考点落在段落主旨与逻辑衔接 |

- **自选**：勾哪几个就出哪几篇（勾了 3 个但只出 2 篇时，会取前 2 个并提示）
- **每篇随机**：从（勾选的）题型里抽，**多篇之间题型不重复**；8 个题型最多出 8 篇，界面限制 1–6 篇
- **出几篇**：1 / 2 / 3 / 4 / 5 / 6

#### 词是怎么分到各篇的

**由程序分配，不靠 AI 自觉。** 选中的词按**轮转**打散到每一篇（第 1 个给第 1 篇、第 2 个给第 2 篇……），
提示词里逐篇写明「这一篇只用这几个词」，所以「均匀分布」是程序保证的。

> 目标词**不要求只出现一次** —— 同一篇里出现多次完全没问题，自然为要。

#### 生成的题目长什么样

每篇一个文件 `单词故事/<日期>-<序号>-<题型>.md`（一天出多篇不会撞名），格式：

```markdown
---
date: 2026-09-14
type: 传统阅读 · 细节题
title: The Quiet Death of a Paper Rule
words:
  - statute
  - monotonous
---

# The Quiet Death of a Paper Rule

（英文原文 400–450 词，目标词加粗）

## 题目
1. According to Paragraph 1, ...
A. ...
B. ...
C. ...
D. ...

## 答案速查
1.C 2.A 3.B 4.C 5.B

## 答案解析
（表格：题号 / 题型 / 答案 / 解析 / 其他选项为什么错）

## 长难句拆解
（挑最难的 3–4 句：断句 / 主干 / 修饰挂在哪 / 逐成分翻译）

## 逐句分析
**S1.** （英文原句照抄）
- **结构**：主句是什么、从句是什么、修饰挂在谁身上
- **翻译**：准确的中文

（全文每一句都要，一路编到 S…）

## 生词回收
（**按词在文中出现的先后**排）
## 中文大意
```

页面里的呈现：

- **原文**：目标词**标蓝**（词形变化也算命中：limp → limping）
- **逐句分析**：全文**每一句**的结构 + 翻译 —— 精读用；「长难句拆解」只挑最难的 3–4 句讲透，
  两节分工不同，别互相替代
- **生词回收**：表里的词**按在文中出现的先后排**（最先出现的在最上面）。
  顺序由程序在**读出来的时候**重排 —— 老笔记不用重生成也立刻受益，文件一个字节都不动；
  认词形变化的口径和标蓝一致（obtain → obtained），正文里找不到的词排在最后
- **题目**：选项**可以点**；**交卷前不给任何对错反馈**；每题标着**分值**
- **对答案**：**全在本地判卷**（对着「答案速查」比），当场出 ✅/❌ 和得分
- **重做**：一键清空重来
- 点选项**只更新那几个选项的样式，不整页重绘** —— 长文的滚动位置不会被顶回顶部

#### 版式：左原文 / 右侧栏

英语阅读是**两栏**的：

| 位置 | 放什么 |
| --- | --- |
| **左（主栏）** | 英文原文 —— 读英文是主线，它永远在；成绩单跟在它下面 |
| **右（侧栏）** | **题目** / **答案解析** / **逐句分析** / **长难句拆解** / **生词回收** / **中文大意**（正文里有哪几节就有几个标签） |

侧栏的规矩：

- **默认只开「题目」** —— 解析和大意还藏着，想看得自己点；**题目就在原文右边**，边读边做
- **点标签开/关，可以同时开几个**：对完答案自动变成「题目 + 答案解析」一起开着
  （上面是对错、下面是定位句和同义替换），不用来回切
- **全收起时侧栏缩成右边一条窄边条**（就几个图标），**原文自动回到中间**；
  开任何一个面板，原文就让位到左边 —— **折叠 / 打开的时候原文位置跟着动**，不用自己去滚去对
- 侧栏是 **sticky** 的：原文再长它也钉在视野里，正好对着原文读；面板开多了侧栏自己滚，标签条钉在侧栏顶上
- 窄屏（≤1080px）自动叠成一栏：原文在上、侧栏在下，标签横着排，照样能收能开

> 「成绩记录」不进侧栏，留在主栏原文下面 —— 它是整篇的**成绩单**，不是「读的内容」。

#### 分值 · 参考用时 · 计时器

**分值不用 AI 写**：考研英语一里，完形 20 空 × 0.5 分、传统阅读 5 题 × 2 分、新题型 5 题 × 2 分
—— **8 个题型单篇都是 10 分**，程序按 `满分 ÷ 题数` 自己算（所以本地判卷的得分是
「对几题 × 每题多少分」，不是「对几题 ÷ 几题」）。

**参考用时同样按真题的比例算**：考研英语一 180 分钟 / 100 分 = **1.8 分钟/分**，
所以一篇 10 分的阅读就是 **18 分钟**（和真题的建议时间一致），每题再按分值摊到
（5 题的一篇 → 每题 3 分 36 秒）。题目上方直接列出每题的参考用时。

**计时器**和今日测试是同一套：一进全屏阅读就开始走，能暂停 / 重置，
按篇目各记各的、存在浏览器本地（刷新不丢），超过参考用时数字变红。

> 「对答案」的得分也会**写进这一篇的 `## 成绩记录`**（标着「本地判卷」）——
> 页面上的分数刷新一下就没了，写进去才留得住，成绩单也才能一直看。

#### 判分：英语不走拍照，程序自己判

英语这一篇**全是四选一**，所以**不用拍照、也不用调模型**：
点完选项按「对答案」，程序对着 `## 答案速查` 比一遍，**按每题分值**算分（对 1 题 = 2 分，不是 1/5），
当场出 ✅/❌、得分、每题判定，并自动展开「答案解析」。

> 让模型去认手写字母属于多此一举 —— 既慢又可能看错。**只有数学 / 408 的大题才需要拍照判分**
> （要在纸上写完整过程），见上面「今日测试 · 拍照判分」那一节。

成绩单就在题目下面：总分 / 满分、每题得分与判定、用时 vs 参考用时、历次成绩。
**成绩写进这一篇的 `## 成绩记录`**（标着「本地判卷」，没有错因那一列 —— 客观题不用归因），
所以页面关掉、刷新都还在，重新生成这一篇时也会自动接回去。

> **对完答案计时自动停**：这一篇已经做完了，顶栏那个数字不该再往上走 ——
> 它同时也是写进成绩记录的「用时」。想再做一遍点「重做」（或长按计时器归零）。

> 判定按 `## 答案速查` 里那行 `1.A 2.C 3.B` 来解析。这一节没有的话，就不显示「对答案」，
> 答案得自己去「答案解析」里看。

### ② 错题 · 题库

左侧按**复习状态（已复习 / 待复习 / 未做）/ 难度 / 考研热度**筛选，右侧卡片列表
（卡片上带「大类 · 科目 · 章节」）。
点开右侧抽屉：难度、热度可点星/点火直接改，考点标签增删，遗忘曲线等级与到期日，
「📄 本题原文」「➕ 续上打卡位置」，打卡时间线（可撤销），
题干，以及四个折叠块（核心考点与主要难点 / 答案 / 解析 / 易错提醒）。

> **答案怎么写的**：小题（选择/填空）给最终结果 + 一句校验；**大题（解答/证明）给的是
> 考场上那种完整标准过程** —— 以「解：」开头、一步一依据、行间公式单独成段、
> 分类讨论写全、结尾出结论，不用「显然 / 易得」跳步，也不自创记号。
> 「解析」块只写思路与易错点，不重复答案里的过程。这条规则写在增题提示词里，
> 所以新题都是按这个标准生成的。

### ③ 错题 · 做题（全屏）

从题库点开某题只是**预览**（半窗口，没有打卡按钮）。预览里点 **▶ 开始做题（全屏）**，
进入单题全屏模式：解析、错因、考点全部藏起来，计时开始，做完再看答案、再打卡。

| 键 | 作用 |
| --- | --- |
| `空格` | 显示答案与解析 |
| `1` `2` `3` | 记「完美 / 普通 / 失败」，做错会接着问错因 |
| `Esc` | 退出 |

#### 计时器 + 参考用时

做题模式和试卷用的是**同一套计时器**：一进来就走，能**暂停**（数字变灰）、**重置**，
按题各记各的、存在浏览器本地（刷新不丢），超过参考用时数字变红。
**点「🤖 判这一题」交卷时自动停** —— 判分要等模型，那几分钟不算这道题的用时
（不然「记录」下来的用时里混着等模型的时间）。

**参考用时**优先用**这道题自己的平均用时**（练过几次就有数了），
没练过就退到**全库中位数**（所有有计时记录的题），两个都没有就不显示参考 —— 不编一个数糊弄你。

#### 单题拍照判分（一题一屏 → 每小题独立打分）

这道题在纸上写完了，就把**手写过程**拍下来传进做题页（可以多张，拖进来 / ⌘V 粘贴 / 选文件），
点「🤖 判这一题」——内置 AI 拿着**这道题自己的标准答案 + 解析 + 易错提醒 + 你的练习历史**
（练过几次、上次什么结果、首次错因）按考研阅卷标准判**这一道题**：

| 给你什么 | 说明 |
| --- | --- |
| **得分** | 0–100，按标准答案的采分点逐步折算（方法对结果错只扣结果那一步；碰巧对不给分） |
| **结果建议** | 从打卡用的那三个词里选：**完美**（独立做对、过程完整）/ **普通**（做出来了但不顺）/ **失败**（没做出来或方法错） |
| **错因** | 从错题本固定的那 8 个词里选一个（判成「完美」就不给错因） |
| **错因分析** | 2–4 句：这次卡在哪、为什么错、下次遇到同类题的信号和第一步 —— **要具体能落地，不是「继续加油」** |
| 丢分点 / 怎么改 | 具体到哪一步扣的、正确写法是什么（里面的公式渲染成 KaTeX，不漏出裸的 `$`） |

**判分本身一个字节都不写盘** —— 结论先填进面板，**你要记什么自己定**：

- **结果**：点 chip 改（AI 建议哪个标着，不对就自己点）
- **错因**：8 个词 + 「不记」，随便换
- **错因分析**：一整个文本框，随便改、随便删；文本框底下还有一行**渲染预览** ——
  分析里常有 `$x\to 0$` 这种公式，文本框里必须是原文（那是要写进笔记的内容），
  预览里显示的是它读起来的样子
- 还有一个开关：**要不要同时写进「首次错因」**（已经记过会提示「勾上就覆盖」，默认只在没记过时勾上）

改完点 **✍️ 记进笔记** 才落盘，一次写三处：**打卡记录**一行（结果 / 日期 / 用时 / 错因）、
`**首次错因**`（勾了才写）、`## 错因分析` 里的「最近一次判分」（**只留最近一次**，不堆流水账 ——
每次练习的结果和错因打卡记录里本来就一条不落）。不想要这次判分就点「不要这次判分」，什么都不会变。

> 判完的暂存图片会自动清掉；写盘前照例先备份，出问题能从 `backups/` 捞回来。

| 想刷什么 | 怎么点 |
| --- | --- |

## 错因分析

每道题都有一个 `## 错因分析` 段，和一个**首次错因**（录入时就该写：你为什么会错）。
之后每一次做错，程序都会问一句「问题出在哪」，记进那条打卡记录：

```markdown
- [x] 第 2 次 · 失败 · 2026-09-14 · 245s · 错因：计算失误
```

错因用固定词表（也允许自己写）：**概念不清 / 方法不会 / 思路方向错 / 计算失误 /
审题错误 / 公式记错 / 粗心大意 / 时间不够**。

总览里的 **🧠 错因分布** 会统计「你到底是怎么错的」——计算失误要练手感，概念不清得回课本，

## 打卡规则与遗忘曲线

**状态只有三种**，而且是「做了就算数」：

| 状态 | 什么时候 |
| --- | --- |
| ⭕ 未做 | 一次都没做过 |
| ✅ 已复习 | **做过了**（不管对没对），下一次复习已经排进遗忘曲线 |
| ⏳ 待复习 | 到日子了，该再做了 |

**任何一次打卡都会排下一次**，间隔由「掌握等级」决定。
规则一句话：**做错 → 明天；做对一次 → 4 天；之后每做对一次翻一倍，没有上限。**

| 掌握等级 | 间隔 | |
| --- | --- | --- |
| 0 | 1 天 | 做错 / 刚学 |
| 1 | 4 天 | 第一次做对 |
| 2 | 8 天 | |
| 3 | 16 天 | |
| 4 | 32 天 | |
| 5 | 64 天 | |
| 6 | 128 天 | |
| 7 | 256 天 | |
| 8 | 512 天 | ≈1.4 年 |
| 9 | 1024 天 | ≈2.8 年 |
| 10 | 2048 天 | ≈5.6 年，基本不用再管它了 |

| 你选的结果 | 等级变化 | 下次什么时候 |
| --- | --- | --- |
| ✅ 完美 | **升一级** | 间隔翻倍（4 → 8 → 16 → 32 → 64 …） |
| 🟡 普通 | **降一级** | 提醒减半，早点回来 |
| ❌ 失败 | **打回 0 级** | **明天**再来（不是当天） |

到了间隔日，这道题自动变成 **⏳ 待复习** 并回到复习队列 ——
所以「做过了」不等于「不用再做了」。

> 为什么不按 1 / 2 / 4 / 7 / 15 天那套走？那张「艾宾浩斯记忆周期表」其实是艾宾浩斯当年
> 做实验时**取样的时间点**，不是复习时机（[墨墨也专门辟过谣](https://memodocs.maimemo.com/docs/ebbinghaus_schedule)）。
> 真正该做的是把间隔拉到**快要忘掉的那一刻**再复习 —— 间隔太短等于白费功夫。
> 这个阶梯就是按这个原则定的：越熟越长，一直熟就一直拉长。

### 打卡次数不封顶

一次不会就一直勾，没有「只能勾三次」这回事：

- 程序每次写回都会**自动往下续 3 组空白位置**，所以从程序里打卡永远不会用完
- 文件里默认先放 3 组；在 **Obsidian 里手动勾**完了，要么照抄一组
  （`- [ ] 第 N 次 · 完美` 三行），要么在详情页点一下 **➕ 续上打卡位置**，程序会把空白位置补齐

记录写回 Markdown 的格式（日期与用时都会自动带上，后两段可省略）：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13 · 245s
- [x] 第 2 次 · 完美 · 2026-09-14 · 192s

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

所以在 **Obsidian 里手动勾这些复选框，程序同样能读到**，两边随时可以混用。
点错了在详情页的打卡时间线上点「撤销」。

> ⚠️ 手动加记录时，「完美 / 普通 / 失败」三个词要原样写，统计靠文字匹配。
> 手动勾的那次没有日期：状态照样算 **已复习**，但**不会排期** ——
> 在程序里再打一次卡，就会从那天开始按曲线排上（日期由程序写，排期才可信）。

## 考点标签

文件夹级的「章节」太粗。每道题还能打**细考点标签**（如「等价无穷小」「夹逼准则」「左右极限」），
存在 frontmatter 的 `points:` 里：

```yaml
points:
  - 1的无穷大型
  - 幂指函数极限
  - 等价无穷小
```

- **增题页每题都有一个「考点」输入框**：题干里出现过的已有考点会**自动勾上**，
  没有的就手打进去 —— **不存在的标签直接新建**，不用先去别处建一个
- 生成提示词时也把这条规则写进去了：AI 写题时按「2–5 个 + 没有的直接新建」打标签
  （提示词里会带上题库现有的全部标签，够用就复用，不够就新建）
- 详情页可以加 / 删标签（输入框有全库补全，回车确认）
- 题库左侧可**按考点筛选**
- 总览里的 **🏷️ 考点薄弱排行** 按累计失败次数排序，直接告诉你该专项突破哪一类

> 同一套标签要**跨题复用**（都写「等价无穷小」），统计才有意义；
> 但**不要为了复用而硬塞**——新考点该建就建。

## 用时分析

复习时每题都记了用时（详情页一打开就计时，复习模式按每题单独计），写进打卡记录末尾的 `192s`。

总览里的 **⏱️ 做得慢的题** 会挑出「做对了但明显比别人慢」的题 ——
以全库中位数为基准，超过 1.5 倍就算慢。**这类题比不会的题更容易抢分。**

## 手机上用（做题端 `/m`）

手机浏览器打开 **`http://<电脑局域网IP>:4173/m`**，就是一套专门的手机做题端：
**今日 / 做题**两屏，底下两个页签。

### 开不开，由设置页里那个开关说了算

电脑端进 **⚙ 设置 → 📱 手机访问**，一个开关，**拨一下立刻生效，不用重启**：

```
📱 手机访问  已打开  http://192.168.1.101:4173/m
             （手机连同一个 Wi-Fi，地址栏输上面那条）
             ⚠️ 局域网里任何人都能打开、也能改你的笔记
```

关掉之后那两行会变成一句「已关闭（局域网连不上）」+ 怎么打开。

**开关背后是两个监听，这是它敢「随时拨」的原因：**

| 监听 | 谁来管 | 什么时候在 |
| --- | --- | --- |
| `127.0.0.1:4173` | 不归开关管 | **永远在**。电脑端、跑测试都不受影响；手机上误关了也能从电脑上开回来 |
| `0.0.0.0:4173` | 就是那个开关 | 只在打开时。**关掉是真的不听这个端口**（不是回一句 403），局域网里谁都连不上 |

两个监听共用**同一套处理逻辑**（把 `request` 事件直接转过去），所以行为一字不差；
关掉时会顺手把已经连上的连接也断开，不是只挡新连接。

开关状态存在 `config.json` 的 **`lanAccess`**（重启之后还是你上次拨的那个位置）：

```json
{ "port": 4173, "host": "127.0.0.1", "lanAccess": true }
```

> 老配置里把 `host` 写成 `"0.0.0.0"` 的**照样管用** —— 那等于开关是开的。
> 现在 `host` 只表示「本机那个监听听哪个地址」，局域网归 `lanAccess` 管，两套说法不再打架。

命令行也能临时改一次（不改配置）：`--lan` 这次开着启动，`--local` 这次关着启动。

> ⚠️ 开着 = 把**能改你错题本**的接口暴露给同一个网络。家里 Wi-Fi 可以，
> 公共 Wi-Fi / 公司网记得关掉。

### 为什么单开一页，而不是把桌面端做成响应式

桌面端是八个页面 + 抽屉 + 键盘流的大前端（`app.js` 六千多行），挤进手机只会又难用又容易改坏。
手机上真正要的只有一条链路：

```
看题 → 在纸上写 → 拍照传上来 → AI 按考研标准判 → 记进笔记
```

所以 `/m` 只做这条链路，界面自己写，但**数据一律走同一套 `/api`** ——
手机和电脑共用同一份 Markdown，没有第二份数据，**谁写的另一边刷新就能看到**。

对应地，手机端**只借**桌面端两样东西：`style.css` 里的设计变量与 Markdown 渲染样式
（`.md-*` / `.fold` / `.callout` / `.panel`），和已经离线内置的 KaTeX。
版式由 `mobile.css` 覆盖成手机的样子 —— 两边不会长得不一样，改主题色也只需要改一个地方。

### 两屏里有什么

**① 今日** —— 倒计时、四张统计卡（今日完成 / 错题待复习 / 本周完成率 / 连续打卡）、
墨墨背单词进度、今天的任务（**勾选直接写回 Obsidian 的周计划**）、本周七天进度条。

**② 做题** —— 三块：

| 块 | 内容 |
| --- | --- |
| 📝 今日测试 | 最新那份卷子一个按钮直达，下面按日期列出全部历史试卷（带「上次多少分」） |
| 📕 错题刷题 | 「⏳ 待复习（N）」一局刷完到期的，「🎲 全部混刷」按优先级排；下面是全部错题，可按 **全部 / 待复习 / 没做过 / 错过 / 已复习** 筛，带搜索框（搜题号 / 考点 / 题干） |
| 📖 英语阅读 | 每篇一个条目，点进去是原文（目标词标蓝）/ 题目两个页签 |

打开一份卷子或一道题之后是**全屏**：顶栏是「← 返回 / 标题 / ⏱ 计时器」，底下是操作条。

### 拍照那一步

手机上最容易做砸的就是这一步，所以给了**两个入口**：

| 按钮 | 走哪条路 |
| --- | --- |
| 📷 拍照 | `<input capture="environment">` —— 直接开后置摄像头，**拍完就传** |
| 🖼 相册 | 不带 `capture`，能多选 —— 拍糊了重拍、或者挑现成的照片 |

> iOS 上传了 `capture` 就只剩相机，想从相册挑旧照片就没路了 —— 所以两个必须都给，
> 不能只留一个。

传之前先在本地缩一遍：

- 手机原图 4000×3000、三四兆，转成 base64 还要再涨三分之一，走 Wi-Fi 又慢又白烧模型额度
- 缩到**长边 2000 像素**、JPEG 质量 0.9（手写过程照样看得清），一般降到几百 KB
- 用 `createImageBitmap(file, { imageOrientation: 'from-image' })` 把 **EXIF 旋转摆正** ——
  不然横着拍的照片传上去是躺着的，模型和人都看不清
- **任何一步出问题都退回原图**：宁可传慢一点，也不能因为浏览器不认识某个 API 就把答案弄丢了

传上来的图按缩略图排在操作条上，**点一下能全屏看**，每张右上角的 `✕` 单独删，
离开这一屏时没用上的会自动从 `uploads/` 里删掉（判分完服务端本来也会清）。

### 判分与记笔记

判分走的**和电脑端完全同一条服务端链路**，口径没有任何差别：

| 做什么 | 走哪个接口 |
| --- | --- |
| 整份卷子拍照判分 | `POST /api/grade`（数学 / 408；总分由服务端加，不采信模型报的数） |
| 单题拍照判分 | `POST /api/grade/question`（0–100 分 + 完美 / 普通 / 失败建议 + 错因 + 错因分析） |
| 英语选择题判卷 | `POST /api/grade/local`（**本地判，不拍照不调模型**） |
| 记一次打卡 | `POST /api/checkin`（结果 / 用时 / 错因 / 错因分析 / 要不要覆盖首次错因） |
| 一键把错题收进错题本 | `POST /api/test/to-bank`（错因、丢分点、该怎么改一起带过去） |

判分是流式的（NDJSON），手机上会显示「已生成 N 字 · 思考 N 字 · 等了多久」——
大题的步骤要抠，通常要一两分钟，**别锁屏**。

**记录什么由你定**（这点和电脑端一致）：AI 判完先把结论填进面板 ——
得分、结果（可点 chip 改）、错因（8 个词 + 「不记」）、错因分析（整段随便改）、
要不要同时写进「首次错因」，**改完点「✍️ 记进笔记」才落盘**；
不想要这次判分就点「不要这次判分」，笔记一个字节都不会动。

不想拍照也行：一题一屏下面直接有 **完美 / 普通 / 失败** 三个按钮，点完选错因，一样记进笔记。

> 手机端**不配置 AI** —— 接口和 key 只在电脑上填（顶栏 ⚙ 设置）。
> 没配好时手机端会明说一句「先在电脑上把 AI 配好」，判分按钮是灰的，不让你白点。

### 计时器与「锁屏回来还在」

- 按**一份卷子 / 一道题**各记各的，存在浏览器本地（和电脑端同一个键名，两边不打架）
- 锁屏、切出去瞄一眼、手滑刷新 —— 回来时间还在，不会白做
- **点一下计时器 = 暂停 / 继续**，**长按 = 归零**（手机上不容易误触）
- 超过参考用时会变红；单题的参考用时优先用这道题自己的平均用时，没有就退到全库中位数
- **交卷就自动停**：整卷点「判这份答案」、英语点「对答案」之后，计时冻在那一刻
  （判分要等模型，那几分钟不算做题用时），再进这一屏也不会自己接着走
- 打卡记完之后自动归零重来，方便再练一遍

还有一处和电脑上不一样：**整屏状态记在 URL 里**（`#q=…` / `#paper=…` / `#reading=…`）。
iOS 切出去久了会把页面丢掉重载，回来直接落回刚才那一屏，不会被打回首页。

### 手机端故意不做的事

写清楚边界，省得下次找半天：

- 不看**计划 / 复盘 / 题型 / 笔记原文**，也不增题 —— 那些是「坐在电脑前做」的活
- 只看**错题本**，好题本没进手机（`/api/questions` 默认就是错题本）
- 没有范围筛选（大类 / 科目 / 章节）和键盘快捷键 —— 手指点，不做键盘流
- 不做跨设备的计时同步：手机和电脑各自记各自的用时

### 加到手机主屏幕

Safari 里「分享 → 添加到主屏幕」，打开就是全屏（`apple-mobile-web-app-capable` 已设），
和原生 App 差不多。不用装任何东西，也不用 HTTPS。

# study · 考研学习台

**Obsidian 存数据 + 本地程序管复习**。六个页面都直接读写你 Obsidian 里的 Markdown：
今日 / 错题 / 好题 / 题型 / 计划 / 复盘。

> 笔记不在程序里看 —— Obsidian 本身更好用，所以 Obsidian 里现在**只留笔记**，其余目录全部隐藏。

> 程序进 git，**笔记 / 计划 / 复盘都不进 git**（私人内容，只留本地 Obsidian）。

| 目录 | 内容 | 在程序里 |
| --- | --- | --- |
| `错题本/` | 错题，`<大类>/<科目>/<章节>/题目.md` | 「错题」页 |
| `好题本/` | 好题，格式与错题本**完全一样，只是没有错因分析** | 「好题」页 |
| `题型本/` | 每个题型一份「通解」 | 「题型」页 |
| `考研/` | 月计划 + 周计划（勾选状态就写在这些文件里） | 「计划」页 + 首页今日任务 |
| `复盘/` | 每日复盘 `26.9/第二周/9.13复盘.md` | 「复盘」页 |
| `高等数学/` 等 | 学习笔记 | 不进程序，在 Obsidian 里看 |

```
错题本/
├── 数学/{高数, 线代, 概率论}/<章节>/*.md
└── 408/{数据结构, 计算机组成原理, 操作系统, 计算机网络}/<章节>/*.md
```

## 启动

**方式一（最省事）**：双击桌面上的 **`启动错题本.command`**。
它会先探服务在不在：在就只开浏览器，不在就启动服务再开。

**方式二**：访达里双击 `错题本-app/启动错题本.command`。

**方式三**：终端

```bash
cd "错题本-app"
node server.mjs              # 启动并自动开浏览器
node server.mjs --no-open    # 只启动
node server.mjs --port 4200  # 换端口
```

打开后地址是 **http://127.0.0.1:4173**

> 窗口关掉服务就停了。首次双击 `.command` 若提示「无法打开」，执行一次：
> `chmod +x "错题本-app/启动错题本.command"`

**环境变量**（临时指向另一份错题本，做实验用）

```bash
NOTEBOOK_DIR=/tmp/另一份错题本 NOTEBOOK_PORT=4199 node server.mjs --no-open
```

## 六个页面

### ⓪ 今日

- **考研倒计时**：距 2027-12-18 还有多少天（`config.json` 的 `examDate` 可改）
- **今天的任务**：从本周周计划里挑出标了今天日期的条目，加上没标日期的本周待办，
  **勾一下直接写回 Obsidian**（补 ` ✅ 日期`，和你原来的习惯一致）
- **本周进度**：一周七天的完成条 + 本周 / 本月 / 错题掌握度三条进度
- **四张统计卡**：今日完成 / 本周完成率 / 错题待复习 / 连续打卡
- 一键进「写今日复盘」或「去刷错题」

### ④ 好题本

和错题本**一模一样**（同一套总览 / 题库 / 复习 / 增题），唯一的区别是
**不写错因分析** —— 好题不是因为做错才收的，不需要归因。
两本书各自有独立的导航树、统计和复习队列，顶栏切一下就行。

### ⑤ 题型大全（通解）

「错题记的是这道题，题型本记的是这类题怎么做」。

- 每个题型一篇**通解**，放在 `题型本/<大类>/<科目>/<章节>/`，分类逻辑和错题本一致
- 一篇通解包含：**适用特征 · 通解步骤 · 例题 · 易错点**
- 每篇带 **难度 ⭐ · 考研热度 🔥 · 掌握度**
- **掌握度不是手写的** —— 由它关联的错题/好题算出来：每道关联题目有自己的遗忘曲线
  「掌握等级」，取平均就是这份通解的掌握度。没练过就显示「还没练过」
- 点开卡片能看到通解正文和**关联的题目**（错题 / 好题分色标注），点题目直接跳过去
- 顶部的 **📋 生成提示词** 会把「已有通解 + 还没归类的题目」打包成提示词，
  发给 AI 之后：能并入已有通解的只改 `related` 关联，新题型才新建 ——
  **同一个题型永远只有一份通解**

通解的 frontmatter：

```yaml
tags: [题型本, 高数, 极限]
type: 通解
category: 计算题 · 求极限
difficulty: ⭐⭐⭐☆☆
heat: 🔥🔥🔥🔥🔥
related:
  - mistakes:极限-01-1的无穷大型（分解因式法）
  - mistakes:极限-02-1的无穷大型（三阶等价无穷小）
```

> 题目 id 的格式是 `mistakes:<文件名>` 或 `good:<文件名>`，两本书里有同名文件也不会混。

### ⑥ 计划 / 复盘

- **计划**：左边按月列出周计划与月计划（带完成度），右边渲染选中计划并按科目分组；
  每条任务都是可点的复选框，勾选即写回 `考研/` 里的原文件。月计划是索引页，整篇渲染只读。
- **复盘**：按日期自动归档到 `复盘/26.9/第二周/9.13复盘.md`（周次取自对应周计划）。
  顶部有 ‹ 前一天 / 日期选择 / 后一天 › / 回到今天，左侧是历史复盘列表。

### 🔁 每日任务约定

计划文件里以 **`🔁`** 开头的任务表示「每天都要做」（比如 `🔁 每日单词 70 个`）。
程序会在**每一天**都把它列出来，不用在文件里复制 7 遍；界面上带一个「每日」小标签。

### ① 错题 · 总览 —— 四层下钻

顶部有一条**范围条**（大类 / 科目 / 章节），三个页面共用这个概念。

| 层级 | 看到什么 |
| --- | --- |
| **全部** | 数学 / 408 两张大卡，各自显示题数、完成率、科目明细；下面是全库待复习表 |
| **某个大类** | 该大类下各科目的情况：题数、完成率、占比、章节分布；点科目卡继续下钻 |
| **某个科目** | 完整总览：统计卡、章节分布环形图、考研热度与难度分布、近 30 天打卡曲线、待复习优先级表、失败过的题 |
| **某个章节** | 同上，但只统计这一章 |

统计卡固定五张：题目总数 / ✅ 复习完成 / ⏳ 待复习 / 累计打卡 / 🔥 连续打卡。

### ② 错题 · 题库

左侧按**复习状态 / 难度 / 考研热度**筛选，右侧卡片列表（卡片上带「大类 · 科目 · 章节」）。
点开右侧抽屉：难度、热度可点星/点火直接改，三个打卡按钮，打卡时间线（可撤销），
题干，以及四个折叠块（核心考点与主要难点 / 答案 / 解析 / 易错提醒）。

### ③ 错题 · 做题（全屏）

从题库点开某题只是**预览**（半窗口，没有打卡按钮）。预览里点 **▶ 开始做题（全屏）**，
进入单题全屏模式：解析、错因、考点全部藏起来，计时开始，做完再看答案、再打卡。

| 键 | 作用 |
| --- | --- |
| `空格` | 显示答案与解析 |
| `1` `2` `3` | 记「完美 / 普通 / 失败」，做错会接着问错因 |
| `Esc` | 退出 |

### ④ 错题 · 复习

一题一屏，答案默认隐藏。

**刷题范围就是顶部那条范围条**，几种典型用法：

| 想刷什么 | 怎么点 |
| --- | --- |
| 全部混刷 | 复习页点「🎲 全部混刷」，或范围条选「全部」 |
| 刷高数 | 点「数学/高数」快捷筹码，或范围条：数学 → 高数 |
| 刷线代 / 概率论 / 408 某科 | 同上 |
| 刷高数的「极限」这一章 | 范围条：数学 → 高数 → 极限 |
| 一次刷好几章 | 「章节多选」里勾多个（不勾＝该范围全部） |

其余选项：抽哪些题（只抽待复习 / 只抽失败过 / 全部 / 只抽已完成）、
出题顺序（按优先级 / 最热优先 / 纯随机）、本局题数（5 / 10 / 20 / 全部）。

「按优先级」= `热度×2 + 难度 − 已打卡次数×0.5 + 失败过×1.5`，再叠一点随机抖动，
所以每次顺序不完全一样，但**最该做的题总在前面**。

**键盘流**：

| 键 | 作用 |
| --- | --- |
| `空格` | 显示答案与解析 |
| `1` `2` `3` | 记「完美 / 普通 / 失败」并进入下一题 |
| `S` | 跳过这题（不计入打卡） |
| `Esc` | 退出本局 |

每记一次结果立刻写进对应的 Markdown 文件，不用结束时统一保存。
一局结束出成绩单：各结果几题、总用时、平均每题用时、逐题结果（点行可回看）。

### ⑤ 错题 · 增题

粘贴题干 → 程序自动**分大类、分科目、分章节、定题型、编号、命名、建骨架、写盘**。
多道题用一行 `---` 分隔，也可以选按空行分隔或整段当一题。

识别依据是关键词打分（极限 / 导数 / 矩阵 / 进程 / TCP……），识别结果**逐题可改**，
编号会自动避开已有文件，绝不覆盖。章节留空时，笔记直接放在科目目录下，不再套一层同名文件夹。

> **答案与解析留空。** 程序不会解题。点「📋 复制提示词给 AI」，
> 提示词里已经带好了完整格式规范，发给 AI（或我）就能拿到带答案的成品。

## 错因分析

每道题都有一个 `## 错因分析` 段，和一个**首次错因**（录入时就该写：你为什么会错）。
之后每一次做错，程序都会问一句「问题出在哪」，记进那条打卡记录：

```markdown
- [x] 第 2 次 · 失败 · 2026-09-14 · 245s · 错因：计算失误
```

错因用固定词表（也允许自己写）：**概念不清 / 方法不会 / 思路方向错 / 计算失误 /
审题错误 / 公式记错 / 粗心大意 / 时间不够**。

总览里的 **🧠 错因分布** 会统计「你到底是怎么错的」——计算失误要练手感，概念不清得回课本，
这两种错的复习策略完全不同，所以这个分布比分数更有用。

> 做题时错因和解析一起被藏起来，做完才显示。

## 图片 → 题目

**不直接存你的原图。** 流程是：

1. 增题页把截图拖进去（可多张，暂存于 `错题本-app/uploads/`）
2. 选好这批题的错因，点 **📋 生成提示词**
3. 把提示词发给 AI（或我）
4. AI 看懂图后：**用文字 + LaTeX 重写题干**，题里如果有图形，**写代码重新画一张**存进
   `错题本/picture/`，再引用 —— 不会把原图贴进笔记

## 数据与安全

| 位置 | 作用 |
| --- | --- |
| `../错题本/**/*.md` | **唯一数据源**。程序读写的就是这些文件本身 |
| `backups/YYYY-MM-DD/` | 每次写入前的自动备份（同一天同一篇只留首次备份） |
| `data/questions.json` | 导出的机器可读快照 |
| `data/stats.md` | 导出的 Markdown 统计报告 |
| `config.json` | 错题本路径、端口、监听地址 |

**没有任何隐藏数据库。** 删掉程序目录，错题本一个字节都不会少。

三条纪律：

1. **定点写回，绝不整篇重写。** 程序只改三处：frontmatter 的 `difficulty` / `heat` / `type`、
   末尾 `## 打卡记录` 区块、以及「本题档案」里对应的那两行。正文、公式、空行全部原样不动。
   已验证：打卡后再撤销，文件与原始状态 **sha256 逐字节一致**。
2. **格式不对就只读不写。** 缺 `## 打卡记录`、frontmatter 缺字段的笔记会在界面标黄，并拒绝为它打卡。
3. **写入前先备份。**

## 打卡规则与遗忘曲线

| 结果 | 含义 | 之后会怎样 |
| --- | --- | --- |
| ✅ 完美 | 独立做对、思路清楚 | 进入遗忘曲线排期 |
| 🟡 普通 | 做出来了但不顺 | 仍待复习 |
| ❌ 失败 | 没做出来 / 做错 | 仍待复习，并打回第 1 级间隔 |

**遗忘曲线**按「掌握等级」走，间隔表是 **1 / 2 / 4 / 7 / 15 / 30 / 60 天**：

| 你选的结果 | 等级变化 | 下次提醒 |
| --- | --- | --- |
| ✅ 完美 | **升一级** | 隔得更久（2 → 4 → 7 → 15 天…） |
| 🟡 普通 | **降一级** | 提醒得早一点 |
| ❌ 失败 | **打回 0 级** | 最快 —— 明天就提醒 |

到了间隔日，这道题自动变成 **⏰ 该复习了** 并回到复习队列 —— 所以「做过了」不等于「不用再做了」。

记录写回 Markdown 的格式（日期与用时都会自动带上，后两段可省略）：

```markdown
- [x] 第 1 次 · 失败 · 2026-09-13 · 245s
- [x] 第 2 次 · 完美 · 2026-09-14 · 192s

- [ ] 第 3 次 · 完美
- [ ] 第 3 次 · 普通
- [ ] 第 3 次 · 失败
```

所以在 **Obsidian 里手动勾这些复选框，程序同样能读到**，两边随时可以混用。
点错了在详情页的打卡时间线上点「撤销」。

> ⚠️ 手动加记录时，「完美 / 普通 / 失败」三个词要原样写，统计靠文字匹配。

## 考点标签

文件夹级的「章节」太粗。每道题还能打**细考点标签**（如「等价无穷小」「夹逼准则」「左右极限」），
存在 frontmatter 的 `points:` 里：

```yaml
points:
  - 1的无穷大型
  - 幂指函数极限
  - 等价无穷小
```

- 详情页可以加 / 删标签（输入框有全库补全，回车确认）
- 题库左侧可**按考点筛选**
- 总览里的 **🏷️ 考点薄弱排行** 按累计失败次数排序，直接告诉你该专项突破哪一类

> 同一套标签要**跨题复用**（都写「等价无穷小」），统计才有意义。

## 用时分析

复习时每题都记了用时（详情页一打开就计时，复习模式按每题单独计），写进打卡记录末尾的 `192s`。

总览里的 **⏱️ 做得慢的题** 会挑出「做对了但明显比别人慢」的题 ——
以全库中位数为基准，超过 1.5 倍就算慢。**这类题比不会的题更容易抢分。**

## HTTP 接口

程序跑着的时候可以直接读，也可以被别的脚本调用：

```
GET   /api/health                               自检
GET   /api/today                                倒计时 + 今日任务 + 本周/本月进度
GET   /api/plans                                计划列表（周/月）
GET   /api/plan?rel=                            单份计划（含原文）
POST  /api/task         { rel, expect, occurrence?, done }   勾选写回计划文件
GET   /api/reviews                              复盘列表
GET   /api/review?date=                         某天的复盘（不存在给模板）
POST  /api/review       { date, content }       保存复盘
GET   /api/questions                            全部题目 + 导航树 + 全局统计
GET   /api/stats?category=&subject=&chapter=    某范围的统计
POST  /api/checkin      { id, result, date?, seconds?, reason? }
POST  /api/undo         { id, attempt, result }
PATCH /api/question     { id, difficulty?, heat?, type? }
POST  /api/points       { id, points[] }                 改考点标签
POST  /api/reason       { id, reason }                   改首次错因
POST  /api/upload       { name, dataUrl }                上传图片（暂存）
GET   /api/uploads                                       暂存的图片列表
DELETE /api/uploads     { names? }                       删除暂存图片
POST  /api/prompt-images { names[], reason? }            生成「图片转题目」提示词
POST  /api/detect       { raw, mode }           识别粘贴的题干，不写盘
POST  /api/new          { items }               批量建题（写盘）
POST  /api/prompt       { stems, category?, subject?, chapter? }   生成给 AI 的提示词
POST  /api/export                               导出 questions.json 与 stats.md
```
